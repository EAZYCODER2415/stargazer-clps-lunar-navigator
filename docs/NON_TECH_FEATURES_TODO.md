# Stargazer features for teachers and the public

This list extracts the proposed features from [the non-technical needs research](NON_TECH_NEEDS_RESEARCHmd). It is a prioritized recommendation list, not a tracker of implementation status.

## P0 — Must-have for meaningful educational and public use

- [ ] **Guided “First Visit” lunar south-pole tour** — An optional, short tour that sets a useful site and camera view, steps through key times, demonstrates Sun/Earth visibility, and explains what is happening in brief captions.
- [ ] **Plain-language scene status** — A continuously updated summary of the current site and time, such as whether the Sun is above the horizon and whether Earth is visible.
- [ ] **Simplified time controls and presets** — Make common moments easy to reach (for example, sunrise or a long-shadow period); keep arbitrary date/time controls in an advanced area.
- [ ] **Teacher activity templates** — Provide at least two short classroom activities with objectives, steps, and student questions; make them printable or exportable.
- [ ] **Glossary and in-context tooltips** — Explain terms such as elevation, azimuth, illumination, and lunar day in plain language.
- [ ] **Power and communications limitations** — Clearly explain that geometric sunlight visibility does not calculate usable power, and Earth visibility does not guarantee a working communications link.

## P1 — Recommended improvements

- [ ] **Three-site comparison mode** — Compare all three curated candidate sites (Malapert Mountain / Massif, Shackleton Crater, and Wiechert Circle) together, with prompts that help users notice differences in sunlight, shadows, and Earth visibility. The current comparison panel displays three entries, but its hard-coded list can duplicate a site depending on which site is selected; ensure each candidate appears exactly once.
- [ ] **Classroom-safe mode** — Offer a predictable set of sites, time ranges, and camera presets while hiding advanced controls.
- [ ] **Accessibility improvements** — Support keyboard use, descriptive text/captions, and clear color contrast for visual layers.
- [ ] **Site story cards** — Explain why each featured site is interesting and how it relates to lunar exploration, with links to reliable mission information.
- [ ] **Misconception-aware explanations** — Add optional short explanations that address common misconceptions about lunar phases, illumination, and Earth–Moon geometry.

## P2 — Optional future features

- [ ] **Exploration challenges** — Add a few optional prompts, such as finding when a site is shadowed while Earth remains visible.
- [ ] **Text or CSV time summaries** — Let users read or export sunlight and Earth-visibility results over a selected interval.

## Priority note

The research's feature recommendation table and developer handover both describe comparison of two sites, but assign different priorities (P0 and P1). This project has three candidate sites, so this checklist expands the recommendation to compare all three; P1 follows the developer handover pending a team decision.
